# AssetLibrary v1.0 - Build Pipeline

This folder contains the reproducible Python pipeline that produced the asset library
(models simplification, PBR channel packing, manifest + documentation generation).

## Requirements

- Windows 10/11
- Python 3.10+ with `Pillow` and `numpy` (the bundled DSH runtime already has both)
- `gltfpack.exe` from [meshoptimizer](https://github.com/zeux/meshoptimizer/releases) (bin/gltfpack.exe)
- Unity 2022.3 LTS

## Pipeline overview

```
tools/
  lib.py                 shared helpers (HTTP, glTF/GLB parser, OBJ exporter, texture packer)
  build_models.py        Poly Haven glTF -> simplify (gltfpack) -> OBJ + PBR textures + manifest
  build_materials.py     ambientCG (1K) + Poly Haven (2K) textures -> Albedo/Normal/Mask + manifest
  build_hdris.py         Poly Haven 1K HDRIs
  combine_library.py     merge manifests -> Documentation/asset_library.json + AssetIndex.csv
  make_sheets.py         thumbnail contact sheets
  make_docs.py           README / guide / credits
```

Each step is idempotent and skips already downloaded files (everything is cached), so the
whole library can be regenerated from scratch with:

```powershell
python build_models.py
python build_materials.py
python build_hdris.py
python combine_library.py
```

Then rebuild the Unity side:

```powershell
Unity.exe -batchmode -projectPath ..\UnityProject_AssetLibrary `
  -executeMethod AssetLibrary.EditorTools.AssetLibraryBuilder.BatchBuild -quit
```

## Customising

- `build_models.py` - `CATEGORIES` / `TARGETS` control which Poly Haven models are used and
  their triangle budget per category.
- `build_materials.py` - `PH_TEXTURES` holds the Poly Haven texture list, `acg_picks.json`
  holds the ambientCG selection (generated by `select_acg.py`).
- Any asset with a CC0 license can be added the same way; the Unity importer only needs the
  naming convention `*_Albedo`, `*_Normal`, `*_Mask` to configure itself automatically.

All source assets are CC0. See `../CREDITS.md`.
